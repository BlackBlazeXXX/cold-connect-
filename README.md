## ✨ What does it do?

Doing cold outreach one-by-one is boring. **Cold Connect** automates the heavy lifting while keeping a personal touch:

- 📥 **Smart Uploads**: Instantly upload your contacts from CSVs or extract data directly from PDFs.
- 🤖 **AI Personalization**: Uses **Google Gemini AI** to read your templates and adapt them for every single contact so they feel hand-written.
- 📈 **Real-Time Analytics**: Beautiful, interactive charts showing exactly who opened and replied to your emails.
- ⚡ **Lightning Fast**: Built on React 19 and Vite for an instantaneous, app-like feel with buttery-smooth animations.

## 🚀 Getting Started

Ready to spin this up locally? It takes less than 2 minutes!

### 1. Installation
Clone the repo and install all the dependencies:
```bash
git clone https://github.com/BlackBlazeXXX/cold-connect-.git
cd cold-connect
npm install
```

### 2. Environment Variables
Create a `.env.local` file in the root folder. You can use `.env.example` as your template:
```env
GEMINI_API_KEY=your_gemini_api_key_here
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

### 3. Run the App
Fire up the lightning-fast development server:
```bash
npm run dev
```
